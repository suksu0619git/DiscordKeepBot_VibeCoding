# 활동 관리 사용법

활동 관리 역할이 있는 스태프만 실행할 수 있습니다.

1. 미등록 멤버: `/활동등록 멤버:@멤버 닉네임:크레딧닉네임`
2. 과거 활동일 지정: `/활동설정 멤버:@멤버 마지막활동일:2026-09-01`
3. 확인: `/활동조회 멤버:@멤버` 또는 `/활동전체조회`

날짜는 YYYY-MM-DD 형식이며 오늘 또는 과거 날짜만 받습니다.
마지막 활동일을 바꾸면 만료일도 해당 날짜 + 설정된 활동 기간으로 다시 계산합니다.
활동 카운트는 기존 규칙대로 마지막 활동일을 1일째로 셉니다.

기존 방식도 사용 가능합니다: `/활동설정 멤버:@멤버 일수:-10`.
이 옵션은 만료일을 오늘에서 10일 전으로 지정하며 마지막 활동일은 바꾸지 않습니다.
활동 카운트를 고치려면 마지막활동일 옵션을 사용하세요. 두 옵션은 동시에 입력할 수 없습니다.

서버를 나가면 활동 관리 명단에서 자동 삭제됩니다. 봇 기동 시에도 전체 멤버 목록을
조회해 이미 나간 사람을 정리합니다. 조회에 실패하면 기록을 보존합니다.
크레딧 참여 이력과 OT DB는 삭제 대상이 아닙니다.
